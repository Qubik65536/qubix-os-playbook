# ADR-0011: Separate explicitly selected Niri session

- Status: Accepted
- Date: 2026-10-14

## Context

Native/user Niri configurations may use Noctalia or another companion shell. Replacing defaults can disrupt a working session or be ignored by personal precedence.

## Decision

Install an additional Qubix Niri session with explicit system configuration and measured companions. Preserve native/personal files. Session selection or free-TTY launch is operator consent.

## Rationale

A complete candidate can be tested and restored without taking ownership of dotfiles or rewriting a manager's startup command.

## Alternatives Considered

Replace system/user configuration, automatically patch native companion integration, or install only inert defaults.

## Consequences

Personal Niri settings are not inherited. Fixed-command managers use the free-TTY entrypoint. Inspect native services for companion conflicts; native graphical/authentication acceptance remains required.
