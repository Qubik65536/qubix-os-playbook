# ADR-0002: CachyOS Niri first

- Status: Accepted
- Date: 2026-10-13

## Context

Supporting many distributions immediately would delay useful desktop behaviour.

## Decision

Develop vertical slices on CachyOS Niri; Fedora/KDE wait until MVP stabilization.

## Rationale

One measured target constrains assumptions and yields testable end-to-end work.

## Alternatives Considered

Parallel Fedora/KDE adapters or generic abstractions first.

## Consequences

Architecture keeps extension points without implementing future adapters.
