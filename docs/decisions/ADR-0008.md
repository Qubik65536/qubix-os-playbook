# ADR-0008: Preserve distribution identity

- Status: Accepted
- Date: 2026-10-13

## Context

Qubix customizes an installed distribution rather than becoming a new one.

## Decision

Keep native os-release and package-manager identity; install Qubix-named branding.

## Rationale

Identity is used by support and software compatibility detection.

## Alternatives Considered

Copy the BlueBuild identity rewrite.

## Consequences

Qubix visual branding does not claim a new distribution or manage upstream identifiers.
