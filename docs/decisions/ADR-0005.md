# ADR-0005: GRUB and Limine in MVP

- Status: Accepted
- Date: 2026-10-13

## Context

CachyOS systems may use different bootloaders.

## Decision

Require both adapters and independent VM tests for MVP; defer boot until after initial desktop.

## Rationale

Supporting only one would leave a required supported installation path incomplete.

## Alternatives Considered

GRUB only, Limine only, or removing boot themes from MVP.

## Consequences

Neither may be deferred beyond MVP; never replace the installed loader for branding.
