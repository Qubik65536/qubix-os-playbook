# ADR-0004: Modular components

- Status: Accepted
- Date: 2026-10-13

## Context

Desktop, boot and splash evolve independently.

## Decision

Use narrow Ansible roles and ordinary platform-specific task files.

## Rationale

Selections stay understandable and the desktop can ship before boot work.

## Alternatives Considered

A monolithic playbook or custom adapter plugin framework.

## Consequences

Orchestration validates dependencies/capabilities before writes; components own named resources.
