# ADR-0012: Noctalia-based Qubix Niri appearance and shortcuts

- Status: Accepted
- Date: 2026-10-14

## Context

The first Qubix desktop candidate uses Waybar, Fuzzel, Mako and Swaybg. The inspected CachyOS target already supplies standalone Noctalia 5.2.1. The operator requests a Noctalia-based desktop, rounded geometry, the Qubix accent #56728b and DMS/macOS-inspired shortcuts.

## Decision

Use installed standalone Noctalia 5.2 or later within major version 5 for the Qubix session's bar, launcher, notifications, wallpaper, clipboard and settings. Keep Foot as the terminal and Niri as the compositor. Supply a Qubix palette and system TOML defaults through Noctalia-specific configuration/state/data roots. Preserve native Noctalia files and ordinary XDG application configuration. Disable app-theme generation into personal files. Use the [desktop design contract](../architecture/desktop-design.md) for appearance and shortcuts.

## Rationale

One existing desktop shell can give these surfaces consistent geometry, colour and behaviour. Noctalia's supported profile roots allow additive deployment while its GUI can retain Qubix-specific user overrides. The installed version and native validator provide concrete compatibility evidence.

## Alternatives Considered

Continue independently styling the classic companions; install DMS as another shell; or rewrite native CachyOS Noctalia settings. The chosen design follows the requested shell and retains the separate-session ownership decision in ADR-0011.

## Consequences

Noctalia becomes a required measured desktop dependency. Legacy companion packages and named files can remain inert after upgrade; the baseline restoration engine still owns their recorded lifecycle. The new profile needs native TOML, palette, IPC, graphical and preservation tests. DMS supplies shortcut conventions only; its shell is not launched. Full application-wide macOS keyboard remapping is outside this change.
