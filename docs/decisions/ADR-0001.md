# ADR-0001: Ansible as deployment engine

- Status: Accepted
- Date: 2026-10-13

## Context

Existing hosts need reproducible managed configuration with minimal dependencies.

## Decision

Use Ansible built-in modules, YAML and Jinja2; Bash only for a small entrypoint.

## Rationale

Idempotency, inventory, privilege controls and check mode already exist.

## Alternatives Considered

A bespoke CLI, shell-only scripts, NixOS, or image generation.

## Consequences

No separate Python application; module semantics and check-mode limits remain visible.
