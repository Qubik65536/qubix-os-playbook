# ADR-0010: Git reproducibility and atomic commits

- Status: Accepted
- Date: 2026-10-13

## Context

Configuration changes need reviewable source identity and recoverable history.

## Decision

Use Git revisions, Conventional Commits and coherent tested logical units; plan runtime revision manifests.

## Rationale

History explains intent while source revisions identify desired managed state.

## Alternatives Considered

One bootstrap dump, automatic pushes, or whole-system reproducibility claims.

## Consequences

No history rewriting/pushing/tagging during bootstrap; runtime state must later include effective config and dirty detection.
