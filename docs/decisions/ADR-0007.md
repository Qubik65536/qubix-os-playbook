# ADR-0007: Configuration ownership

- Status: Accepted
- Date: 2026-10-13

## Context

Users and distributions already own valuable defaults and personal settings.

## Decision

Assign Managed, Default, or Preserved ownership; use additive resources and explicit personal adoption.

## Rationale

Ownership makes reconciliation and recovery boundaries reviewable.

## Alternatives Considered

Overwrite all configs or avoid all system defaults.

## Consequences

Existing defaults need a backup/activation policy; personal files remain untouched by bootstrap.
