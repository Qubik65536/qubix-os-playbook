# ADR-0009: Boot customization safety

- Status: Accepted
- Date: 2026-10-13

## Context

Incorrect boot edits can make a machine unavailable.

## Decision

Boot/splash remain opt-in; require active evidence, minimal edits, backups, version checks and disposable VM recovery.

## Rationale

Installed-package assumptions and static syntax alone do not establish a working boot chain.

## Alternatives Considered

Guess from distribution defaults or replace whole boot configurations.

## Consequences

No development-host boot/initramfs operations without explicit authorization; ambiguity fails safely.
