# ADR-0003: Documentation-first development

- Status: Accepted
- Date: 2026-10-13

## Context

The project has consequential ownership and boot safety requirements.

## Decision

Define substantial feature contracts before source; update actual behaviour with implementation.

## Rationale

Reviewable intent prevents undocumented destructive changes and stale promises.

## Alternatives Considered

Document after a full implementation or rely on source alone.

## Consequences

Documentation-only foundation precedes source commits; small fixes do not need new design documents.
