# Adding an adapter

Adapters are ordinary component role task files with platform variables, not a framework. Document required host evidence, version support, resource paths, minimal edits, verification, and recovery first.

Select only from validated capabilities. Installation presence is not active-state evidence. Reject ambiguity rather than allowing a distribution default to decide. Retain a common component contract while keeping GRUB/Limine and dracut/mkinitcpio behaviours distinct.

Add fixtures for unsupported/missing/ambiguous evidence and VM coverage for activation/recovery. Update compatibility tables only with actual tested versions. Fedora and KDE adapters wait until the CachyOS Niri MVP is stable.
