# Installation

Status: **Planned procedure**. No deployment command is operational in the documentation foundation.

Use an existing CachyOS Niri installation; the project does not install Linux or create an ISO. The controller needs Ansible and the target needs Python. A minimal wrapper and local tool installation procedure will be documented when implemented.

Before future deployment, read [configuration](configuration.md), [deployment](deployment.md), and [restoration](restoration.md). Verify target compatibility before privilege escalation. Bootloader and Plymouth settings must remain disabled until their adapters are tested.
